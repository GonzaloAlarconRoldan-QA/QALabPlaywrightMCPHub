📋 Executive Summary

The Waycroft is a leasing-agent sales center portal built on the Vysta platform. Agents use it to manage prospects, conduct property tours, and send unit information to interested tenants.

Core functionality — agent authentication, guest/client management, tour tracking, unit availability, and neighborhood mapping — is largely operational. However, the application has critical content gaps (Lorem Ipsum text, placeholder gallery images, file metadata watermarks on photos), significant data quality issues ($0 unit pricing, missing dimension data), and 7 JavaScript console errors.

⚠️ The application should NOT be used in live leasing presentations until the 5 critical issues are resolved. Placeholder content, broken gallery images, and watermarked kitchen photos are visible to prospective tenants.

🎨 UI / UX Findings
UX-01 · Medium
Complete theme break in CRM screens
The All Clients page, guest detail, and analytics screens use a stark white design system while the main portal uses a navy/gold brand theme — visually jarring when switching between presentation and management contexts.
UX-02 · Medium
Share button auto-selects unit row unexpectedly
Clicking the per-row Share icon also checks the SELECT checkbox and reveals a bottom action bar (Share / Remove from Favorites / Deselect). This side effect is invisible to the user and creates confusion about what is being acted upon.
UX-03 · Medium
PIN login has no forgotten PIN recovery or lockout messaging
No "Forgot PIN" option exists. After entering a wrong PIN the system simply clears the dots with no error message, no lockout counter, and no indication of how many attempts are allowed.
UX-04 · Low
Home dashboard tiles have no visible hover affordance
The 6 home tiles appear interactive but have no hover cursor change or overlay effect visible in testing — users unfamiliar with the interface may not know they are clickable buttons.
UX-05 · Low
Inconsistent tab/filter patterns across the app
Gallery filters use pill-style toggle buttons. Client list uses column group headers styled as tabs. Availability uses top-right button groups. Unit list uses a "SELECT 2 TO COMPARE" banner. No consistent filtering pattern is established.
UX-06 · Low
"Select Guest" initials replacement is a good pattern — but tour end state is ambiguous
During an active tour "Select Guest" is replaced with the guest's initials (e.g., "FL") — a clear, effective affordance. However, after a tour ends the button reverts to "Select Guest" text with no toast or indication that the tour was recorded, which could leave agents uncertain.

💡 Recommendations

🚨 IMMEDIATE — Block go-live until resolved

  • Replace Lorem Ipsum About page text with real property marketing copy
  • Upload actual property photography to Gallery (ALL, RESIDENCES, and AMENITIES tabs)
  • Remove/crop file metadata watermarks from all Finishes photos (Kitchens and Bathrooms)
  • Fix $0.00 pricing for units 828 and 328 in the data source

⬆️ HIGH — Resolve before public leasing use

  • Populate EXTERIOR sqft data for all units, or remove the column if not applicable
  • Fix 0 BEDS / 0 INT. SIZE data for units 746 and 363
  • Investigate and fix the 7 JavaScript console errors (especially those appearing on Availability and Amenities)
  • Implement or replace the Analytics Dashboard button — either wire up the route or remove the button
  • Add real content to the Amenities section (amenity list, descriptions, interactive floor plate, or photo gallery)
  • Fix the client list "WHEN" column to reflect the most recent tour date after a tour ends
  • Fix Access Summary (Total Accesses / Last Access) data sourcing

🔧 MEDIUM — Quality improvements

  • Add phone input masking (e.g., auto-format to +1 XXX-XXX-XXXX) to reduce agent friction
  • Fix SELECT checkboxes in Unit List to enable the COMPARE feature
  • Populate VIEW field on Unit Details for all units
  • Move banks to a "Financial Services" or "Services" category in Neighborhood POIs
  • Make LEASING TOUR/EMAIL/TOURS tab headers functional or remove them if they are decorative labels only
  • Fix Connect panel pointer-event z-index to allow Settings gear access independently
  • Display Company and Country on the guest profile detail view

✨ LOW — Polish and consistency

  • Standardize property name — pick "Wilson's Blvd" OR "Wilson & Glebe" and use it everywhere
  • Align phone validation error copy with other field messages ("Phone is required" / "Invalid phone number")
  • Add subtitle text to Update Client modal consistent with Create Client modal
  • Normalize analytics page name capitalization (all title case or all lowercase)
  • Replace internal model codes (BH-24_BB-24_BW-24) with user-friendly floor plan names
  • Change Share modal button to "Send" for clarity
  • Add visual confirmation/feedback when the TOUR play button is clicked from the client list
